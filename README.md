# SWYNEX Interactive Dashboard

## Task 3: Student Performance Dashboard

### Objective
To create an interactive dashboard using Python, Streamlit, Pandas, and Plotly.

### Dataset
Cleaned student dataset containing:
- Student ID
- Name
- Age
- Marks
- Department

### Key Performance Indicators
- Total Students
- Average Marks
- Average Age

### Visualizations
- Marks Distribution
- Average Marks by Department
- Age Distribution
- Age vs Marks

### Interactive Feature
Department filter to explore student performance.

### Tools Used
- Python
- Streamlit
- Pandas
- Plotly
